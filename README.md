# Library-Management-System
A Library Management System designed to efficiently manage library operations such as book records, member management, and borrowing/returning transactions. This system helps librarians organize and track books while providing an easy interface for managing library activities.

🚀 Features

📖 Add, update, and delete book records

👤 Manage library members

🔄 Issue and return books

🔍 Search books by title, author, or category

📊 Track available and borrowed books

🗂 Maintain borrowing history


🛠 Technologies Used

Programming Language: (VB.NET, C#)

Database: (Ms. SQL SERVER)


📂 Project Purpose

This project was developed to demonstrate database management, CRUD operations, and system design concepts while solving real-world library management problems.

▶️ How to Run

Clone the repository

Install required dependencies

Configure the database

Run the application
